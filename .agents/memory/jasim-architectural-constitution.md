name: JASIM architectural constitution
description: Durable acceptance philosophy and implementation boundaries for JASIM universality.
---

JASIM universality must emerge from shared entities, relationships, capabilities, policies, workflows, state, providers, and projections—not from domain-specific handlers, routers, agents, services, pages, or Bubble components.

**Why:** The architectural teaching specification explicitly treats its scenarios as acceptance philosophy rather than a feature backlog, and requires truthful missing-primitive/provider/resource outcomes instead of vertical workarounds.

**How to apply:** Before Universal Capability Fabric, Economic Network, or real-world execution work, close Block 0 Kernel Trust + Recovery: authentication, complete owner isolation, trusted execution boundaries, Run restart recovery, and migration safety. Do not implement the teaching scenarios as features, and do not start a later block automatically after Block 0.
