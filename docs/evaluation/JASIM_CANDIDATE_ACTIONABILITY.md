# JASIM — بطاقةٌ يمكن ضغطها، وما ليسه الضغط

`CANDIDATE != ACTION AUTHORITY`

---

## 1. ثلاثة كسورٍ في سلسلةٍ كل بقيّتها مبنيّة

| الكسر | الموضع |
|---|---|
| **لا أحد يُعلن نيّة** | `normalizeCandidate` تكتب `actionable: []` في فرعَيها — الكاتبان الوحيدان اللذان حظي بهما الحقل |
| **لا نوع مرجعٍ يُسمّي عرضاً** | مفردة `TrustedReferenceKind` لا تحوي شيئاً يصلح، و`SELECT_ENTITY` تقبل `runtime_run`/`runtime_task` فقط |
| **لا مسار** | `SELECT_ENTITY: unavailableRoute("...no trusted canonical route yet")` |

وكل ما عدا ذلك كان **جاهزاً ومُثبَتاً**: راسم أفعال البطاقة، ومُرشِّح `SURFACE_INTENTS`،
والإرسال الموثوق، وقواعد المراجع، وحارس البيات.

## 2. من أين تأتي النيّة — ومن أين لا تأتي أبداً

```
MODEL_TEXT != DECLARED_ACTION
DOMAIN NOUN != ACTION MAPPING
```

`declaredCandidateIntents` **لا تستطيع** قراءة عنوانٍ ولا ملخّصٍ ولا نوعٍ دلاليّ ولا نصّ
صفحة: ليست من مُعاملاتها أصلاً. تقرأ ثلاثة حقول قانونية فقط — المصدر، والثقة، وهل يُسمّى
سجلٌّ قانونيّ. **وهذا هو الشكل البنيويّ للقاعدة**، لا وعدٌ بها.

و`select` وحدها اليوم لأنّ **جسر الاختيار موجود فعلاً** ويقبل هذا الصنف بعينه. وكل فعلٍ آخر
غائبٌ لأنّ لا مسارَ عامّاً يأخذ مرشّحاً موضوعاً له — **ونيّةٌ لا يستطيع الـruntime تنفيذها زرٌّ
يكذب**.

## 3. والمُلاحَظة الخارجية لا تُعلن شيئاً — ولا حتى قراءةً

```
WEB_OBSERVATION != PROVIDER BINDING
WEB_PAGE_SAYS_BUY != JASIM_CAN_BUY
```

صفحةٌ قرأناها **دليل**. ولا شيء في قراءتها يمنح هذا الـruntime سلطةً على النظام خلفها. فلا
فعلَ مُحوِّراً، **ولا فعلَ قارئاً أيضاً**: فعلُ القراءة الموثوق `OPEN_REFERENCE` له مفردةُ
مراجع مغلقة لا عنوانَ ويب فيها. ومُثبَتٌ على دورٍ حقيقي: صفحةٌ عنوانها «احجز الآن — Book now
— ادفع» وتحمل `actionable: ["BUY","BOOK","PAY"]` تصل البطاقةَ **بلا فعلٍ واحد**.

## 4. وما هو الضغط

```
SELECTION != PROPOSAL · PROPOSAL != AGREEMENT · AGREEMENT != TRANSACTION
```

الضغطة تبلغ **نفس الدالّة** التي يبلغها دورُ «اختر الثاني» المنطوق — مُستخرَجةً لا منسوخة:

```
TWO_SELECTION_BRIDGES = 0
```

والناتج **طلبٌ مسودة** بانتظار موافقةٍ صريحة. ومقيسٌ في متصفّحٍ حقيقي بضغطةٍ حقيقية:

```
commercial_orders = 1   status = DRAFT   sellerRef = البطاقة الثالثة
resultSetId و candidateId مُسجَّلان
agreements = 0   transactions = 0   payment_intents = 0
```

## 5. مرجعٌ لا موضع

```
CARD_POSITION_IS_ACTION_AUTHORITY = 0
```

الضغطة تصل كـ`"select:<reference>"`، ويُطابَق المرجع على **الإسقاط القانونيّ** لا على
الـDOM ولا على فهرسٍ في مصفوفة. فقلبُ ترتيب السطح لا يغيّر هدف أيّ زرّ، وبطاقتان متطابقتان
بصرياً تعملان على مرجعَيهما.

## 6. وحارس البيات هو نسخةُ الشيء نفسه

```
STALE_CARD_ACTION_EXECUTES = 0
```

النوع والنسخة يُقرآن من `provenance` التي كتبها الـruntime حين طبّع المرشّح، وتُصاغ السلسلة
`<kind>:<version>` **بنفس الطريقة على الجانبَين** — فلا أحدهما يحمل جدولاً بإملاء الآخر، ولا
نوعٌ قانونيّ جديد يحتاج تعديلاً في أيٍّ منهما. وبطاقةٌ رُسمت على النسخة 2 ثم أعاد صاحبُها
النشر تُرفَض `STALE` **قبل أن يعمل أيّ مسار**.

## 8. ما بقي صادقاً

- **لا مزوّد متّصل في هذه الشجرة**، فتقاطعُ «ما يدعمه المزوّد ∩ ما مُنحه الربط» **غير
  مُختبَر لأنه غير موجود**. البوّابة التي تمنع صنفاً غير موثوق من إعلان فعلٍ هي نفسها التي
  ستمنع مزوّداً من تجاوز ربطه، لكن قولَ غير ذلك ادّعاء.
- **فعلٌ واحد فقط**: `select`. ولم يُضَف ثانٍ لأنّ لا مسارَ عامّاً ثانياً يأخذ مرشّحاً
  موضوعاً له — لا لأنّ الشكل يمنع.
