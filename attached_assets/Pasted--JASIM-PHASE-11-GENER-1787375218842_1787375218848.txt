19. IMAGE RETRY VS REGENERATE
=====================================================================

These are NOT the same thing.

RETRY:
same intended execution after a technical failure,
subject to canonical idempotency/retry policy.

REGENERATE:
a new creative request that may intentionally produce a different image.


UI and backend should not confuse them.

Server determines safe retry.

User explicitly requests regenerate when a new generation is desired.
