=====================================================================
1. JASIM PRODUCT PRINCIPLE
=====================================================================

JASIM must NOT send every request to the strongest/most expensive model.

JASIM must also NOT degrade normal conversations by routing them to
an extremely weak classifier-sized model.

The required principle is:

USE THE CHEAPEST SUFFICIENT INTELLIGENCE.

Not:

USE THE CHEAPEST MODEL.

And not:

USE THE STRONGEST MODEL FOR EVERYTHING.


JASIM should have a capable high-volume default language model
for the vast majority of normal interactions.

Stronger models are reserved for tasks that actually justify them.


=====================================================================
2. VERY IMPORTANT — DO NOT CONFUSE MODEL POWER WITH AUTHORITY
=====================================================================

MODEL POWER
!=
ACTION AUTHORITY


Example:

User:
"حوّل 500 دينار إلى هذا الحساب."

The language is simple.

It may only require T1 intelligence to understand.

But execution remains:

T1 understanding
→ canonical intent/proposal
→ Policy
→ Approval
→ Trusted Executor
→ Receipt
→ Verifier


Do NOT invoke T3 merely because an action is high-risk.

Security is enforced by Kernel/Policy/Executor.

Not by choosing an expensive model.


Likewise:

T3 can generate a very complex plan.

But T3 receives ZERO additional authority to execute it.
