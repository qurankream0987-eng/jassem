# PHASE 1 — GENERAL REFERENCE RESOLUTION

قبل تفعيل التنفيذ الخارجي، أكمل Reference Resolution عامة.

لا تبنِ:

```text
BubbleReferenceResolverOnly
```

بل:

> GENERAL RUNTIME REFERENCE RESOLUTION

يجب أن يستطيع المستخدم الإشارة طبيعيًا إلى أشياء سبق إنشاؤها أو استخدامها.

أمثلة:

```text
متجري
منصتي
الفقاعة التي فيها الآيفون
السيارة التي طلبت منك بيعها
الإعلان السابق
المنتج الذي أضفناه أمس
الخدمة الثانية
المهمة السابقة
العملية التي ما زالت تنتظر
```

## 1.3 حالات الغموض

مثال:

```text

```

لا تخمّن.
