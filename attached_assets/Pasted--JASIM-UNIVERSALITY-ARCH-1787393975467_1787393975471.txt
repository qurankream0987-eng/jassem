=====================================================================
WHAT "UNLIMITED GENERALITY" REALLY MEANS
=====================================================================

It does NOT mean JASIM magically contains infinite code.

It means:

A FINITE / EXTENSIBLE SET OF GENERAL TRUSTED PRIMITIVES

+
GENERATED SCHEMAS

+
GENERATED WORKFLOWS

+
CAPABILITY COMPOSITION

+
PROVIDER ADAPTERS

+
GENERATIVE UI

=
A VERY LARGE / OPEN-ENDED SPACE OF USE CASES.


When a completely new problem appears, JASIM should attempt:

1. understand the goal;
2. model required entities/state;
3. determine required capabilities;
4. compose existing generic capabilities;
5. generate the correct workflow;
6. generate the smallest sufficient UI;
7. execute through trusted boundaries;
8. identify any missing provider/resource/human decision truthfully.

It must NOT react by creating a new vertical.
