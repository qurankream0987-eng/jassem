### A. Adaptive Surface

### B. Active Generative Workspace

The Workspace represents:

THE CURRENT VISUAL CONTEXT OF THE ACTIVE GOAL.

It may contain:

Conversation
Generated Views
Current Results
Selected Entities
Current Goal
Current Action
Status

The Workspace may MORPH as the task evolves.

Example:

Search
→ Results Workspace

Then:

"قارن الثاني والرابع"

→ Comparison Workspace

Then:

"خذ الرابع واحجز السبت"

→ Selected Entity + Calendar + Approval

The VIEW changes.

The OPERATIONAL STATE must remain.

### C. Living Object

A Living Object represents:

SOMETHING THAT CONTINUES AFTER THE CURRENT RESPONSE.

Examples:

monitor
active order
delivery
World
project
negotiation
booking
long-running Run
subscription task

Rule:

IF IT ENDS WITH THE RESPONSE
→ NO LIVING OBJECT REQUIRED

IF IT CONTINUES BEYOND THE RESPONSE
→ LIVING OBJECT MAY BE JUSTIFIED

### D. Bubble

Bubble is NOT architecture.

Bubble is NOT canonical state.

Bubble is NOT a data model.

Bubble is ONE possible presentation form.

A Bubble / Orb / Capsule / Panel / Sheet / Grid / Workspace are visual render modes.
